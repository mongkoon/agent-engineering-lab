# 02 — Commerce CS Agent (planned MVP)

A fictional shop agent to practice practical agent engineering. This component is a roadmap, **not yet implemented**.

## Minimal scope

- Tool selection: `get_order`, `get_policy`, `cancel_order`, `escalate_to_human`
- Deterministic order-state validation (SQLite)
- Human approval before changes to an order
- Error handling and safe escalation
- Reproducible tests and agent evaluations

No real payment, e-commerce platform, or customer data will be connected.
